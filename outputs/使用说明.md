# 工具宝匣使用说明

## 启动

优先双击 `启动工具宝匣.cmd`。当前电脑的 Windows Script Host 被系统策略禁用，因此不要使用 VBS 启动入口。

`工具宝匣.exe` 是已编译的独立程序；若系统提示策略阻止，请改用 VBS 入口。

## 内置组件

OCR运行时以及`chi_sim`、`eng`语言数据已经打包进`工具宝匣.exe`。首次识字时程序会自动释放组件，不需要CMD、安装器、管理员权限或系统PATH。

当前完整项目中已包含局域网FTP和视频转脚本所需环境；视频转写首次使用时仍需要联网下载本地语音模型。

## 截图

“截图识字与搜索”位于“图片应用”分组。启用隐藏客户端后，截图期间仅最小化工具宝匣，任务栏图标仍保留。框选完成后右键菜单固定为：

1. 复制识别
2. 搜索图片
3. 保存本地
4. 退出截图

框选结束后，截图浮窗保持在原框选位置和原尺寸，不再移动到屏幕右上角。

## 界面

主页工具按钮仅显示图标和名称，可双击打开。设置按钮位于主页右上角。说明栏中的`★`/`☆`图标用于取消置顶/置顶。说明栏右侧中央的 `▶` 用于向右收起，收起后的 `◀` 用于向左展开。设置页支持字体大小、界面缩放、浅色/深色/跟随系统，以及简体中文、繁體中文、English。

## 文章提炼

短文输出核心要点；长文输出一句话总结、3–7条核心要点和结构化完整摘要。技术术语、命令、版本号和配置项保持原样，重要结论附段落线索；原文缺失、推断、存疑和作者观点会显式标记。

## 删除安全

空文件、空文件夹和重复文件页面均只提供“移入回收站”，不提供永久删除。
